**SQL Lens now requires the anthropic 2.x Python SDK, and `llm.temperature` is no longer accepted** — SQL Lens now installs with `anthropic>=2.8,<3`. The 2.x SDK and the Anthropic API version it sends reject a sampling temperature, so the `llm.temperature` setting (`SQLLENS_LLM__TEMPERATURE`), added earlier in this unreleased cycle, is no longer accepted: a config that sets it, to any value, fails to load, and `sqllens validate` and `sqllens serve` exit with code 2 and ask you to remove it. No other setting replaces it. **Gateway operators:** the 2.x SDK sends the API key as `Authorization: Bearer <key>` instead of `X-Api-Key`. SQL Lens has no setting to send the key as `X-Api-Key`, so a gateway behind `ANTHROPIC_BASE_URL` that reads only `X-Api-Key` should be changed to read the `Authorization` header. See [Configuration](docs/external/configuration.md#section-llm). (#370)
