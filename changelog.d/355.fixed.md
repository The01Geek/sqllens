With row-level security rules active on PostgreSQL, a quoted call to a built-in
PostgreSQL function that SQL Lens's SQL parser does not recognise, such as
`"quote_ident"(name)`, now runs with its written case instead of failing with
"function does not exist". With row-level security rules active on SQLite, the
result column of an unaliased call to a function the parser does not recognise
is now named with the case it was written in, for example `printf('%s', name)`
instead of `PRINTF('%s', name)`. (#314)
