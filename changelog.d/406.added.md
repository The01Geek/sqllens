A new `[access_rules] allow_admin_tools` switch, off by default, registers a
read-only `get_access_rules` tool and an access-rules widget. They list the
`[[rls]]` rules and the rule sets the running server loaded: the rule-set
file's path and the SHA-256 hash of the bytes read at load (compare it with
`sha256sum` of the committed file), its binding and metadata key names,
whether the catalog check has passed, and each rule set's scope, `source`
fields, refusal state, tables and row rules, with the time the configuration
loaded. Any caller that passes the server's authentication can read the
listing, so turn the switch on only on an instance end users' assistants
cannot reach. (#404)
