Absolute SQLite paths in `database.url` now work: `sqlite:////var/data/app.db`
(four slashes) opens `/var/data/app.db`, `sqlite:///data/app.db` (three slashes)
is relative to the directory the server starts in, and `sqlite:///C:/data/app.db`
works on Windows. A SQLite URL with a host or `?...` query parameters is now
rejected with a clear error. With `read_only = true`, a SQLite `database.url` that
points at a missing file now stops `sqllens serve` at startup with an error naming
the path, instead of creating an empty database whose queries all fail; this
includes the unedited configuration written by `sqllens init`. (#318)
