On PostgreSQL, the read-only guard's function denylist now also refuses
functions that run query text passed as a string or read a relation named by a
text argument, matching the existing `query_to_xml` family: `ts_stat`,
`ts_rewrite`, tablefunc's `crosstab`, `crosstab2`, `crosstab3`, `crosstab4`
and `connectby`, xml2's `xpath_table`, dblink's `dblink_build_sql_insert` and
`dblink_build_sql_update`, and pageinspect's `get_raw_page` and
`bt_page_items`. Every overload of these names is refused, including the
`ts_rewrite` form that takes only `tsquery` arguments.
