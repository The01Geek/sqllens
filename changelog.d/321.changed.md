SQL Lens is now tested on Python 3.13 and 3.14 in CI alongside 3.11 and 3.12, and
the package lists all four versions as supported; the minimum stays Python 3.11.
A JSON memory bundle or golden file that nests arrays and objects more than 64
levels deep is rejected with `bundle JSON is too deeply nested to parse safely`
on every supported Python version, so the same file gets the same error whichever
version runs SQL Lens. Valid bundles nest only a few levels and are unaffected. See
[Bundle size limits](docs/external/managing-memory.md#bundle-size-limits).
