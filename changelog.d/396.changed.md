`pip install sqllens` now includes the MySQL driver (PyMySQL, with the `rsa`
extra MySQL 8.0's default authentication needs). The `mysql` and `all` extras
are still accepted but add nothing beyond the core install. If PyMySQL is
missing, `sqllens serve` and `sqllens validate --check-db` now report a broken
install and ask you to reinstall `sqllens`.
