With `show_details` on, a server with a rule-set file or `[[rls]]` rules no
longer labels the SQL in a `query_database` answer as the executed SQL. Those
access rules change the query before MySQL runs it, so the answer now shows the
SQL under `**Query as written:**`, starting with the line
`-- SQL Lens applies this server's access rules to queries before running them, so the query that ran can differ from this text.`
The `sqllens/query` metadata entry carries the same text in `sql` and adds
`"as_written": true`. A server with neither keeps the `**Executed SQL:**`
heading and unchanged metadata.
