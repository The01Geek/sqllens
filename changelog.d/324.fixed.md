`query_database` now gets the rows of a read that starts with `WITH`, an
opening parenthesis (such as `(SELECT …) UNION (SELECT …)`), a `--` or `/* */`
comment (or `#` on MySQL), or that writes `SELECT*FROM` without a space, and of a
MySQL `SHOW TABLES`-style schema lookup. Such a read was reported to the agent as
a row count, with its result rows dropped, so the agent could not answer from
them. A query whose CTE name starts with a catalog
prefix (for example `WITH pg_recent AS (…)` on Postgres) is no longer treated as
a schema lookup, so its result is shown. SQL Lens now requires `sqlglot` 30.22
or later; pip installs it automatically on upgrade. (#304)
