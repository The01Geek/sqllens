`sqllens verify-memory` now runs while a rule-set file is configured. Give it
`--rule-set`, `--user` and, when the file binds more than one account,
`--account` (with exactly one bound account it is used by default). Every
golden case then runs as a `query_database` request under that rule set,
account and user, so the set's tables, columns and row rules apply to it.
Before the first case the command checks the identity and the rule-set file
against the database, and stops with exit 1 naming the refusal and the values
it used. Without a rule-set file, these options are refused. A configuration
that fails to load now prints only the configuration error. (#376)
