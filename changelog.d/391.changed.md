SQL Lens now requires version 2.x of the MCP Python SDK (`mcp>=2.3.0,<3`) and no longer installs alongside mcp 1.x. `build_server` returns an `MCPServer` instead of a `FastMCP`. Tools, widget resources, tool and resource error messages, and the stdio and Streamable HTTP endpoints are unchanged. Row-level-security rules that read request metadata now never see the progress token or keys starting with `io.modelcontextprotocol/`; a caller key spelled `progress_token`, forwarded before, is now dropped by the SDK. Python clients built on mcp 2.x must raise `max_sse_event_size` above its 1 MiB default to read the query-results or memory-admin widget over Streamable HTTP. (#371)
