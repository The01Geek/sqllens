Query result tables now say when they are cut. When the display size limit
leaves rows out, the table widget shows "Showing the first N of M rows" above
the search bar and the Markdown answer notes how many rows were left out. When
the query stopped at the row limit, both say so and name the limit in effect.
Export CSV warns that the file holds only the rows shown. The agent is told
when the user's table is cut and is instructed to state how many rows the
table shows and how many the query returned, and never to call a result table
full or complete. When a query returns rows and is not a schema lookup,
but its column headers alone are too large to show or its table could not be
built, the answer now has a text block saying the rows could not be
displayed. (#337)
