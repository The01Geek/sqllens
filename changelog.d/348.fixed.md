The widget export buttons (the CSV export on query result tables and the
JSON/CSV export in the memory admin Danger zone) now report what actually
happened. Before, a download the user cancelled or the host refused fell
through to a silent clipboard copy reported as success. Now a completed
download says "Downloaded <filename> ✓", a cancelled or refused download says
it was cancelled or blocked and copies nothing, and a host save dialog is given
up to 10 minutes before timing out. A clipboard copy now happens only when the
host cannot save files or the download request fails, and its message says why.
The manual-copy fallback no longer shows the filename in the memory admin
widget. (#340)
