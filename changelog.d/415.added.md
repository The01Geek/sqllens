The memory-administration panel now shows each memory's [memory groups](docs/external/managing-memory.md#memory-groups). Browse has a `groups` column (`untagged` for a memory with no groups, `⚠ unreadable` for one whose stored group list is damaged), the row-detail view shows a memory's groups, and a `groups` filter lists only the memories in one or more chosen groups, untagged memories or unreadable ones. The filter covers the memories Browse has loaded (the newest 1,000 of the selected type). The panel's Import and Export descriptions now describe how duplicates' groups are merged and when a CSV export is marked lossy.
