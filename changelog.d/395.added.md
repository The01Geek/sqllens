Rule sets now support row rules for MySQL. A table in a rule set can carry a
`row_rule` (`compare`, `any_of`, `all_of`, `owner_via`, `inherit` or
`referenced_by`) that limits which of its rows the selected role sees, and
SQL Lens filters each such table before the assistant's SQL reads it. The rules
are validated and compiled when the configuration loads, and the startup
catalog check also confirms that every compared column has a MySQL type the
rule's `value_type` accepts. Queries over a table with a row rule can be slower,
because MySQL builds the table's visible rows before applying the query's own
conditions. A file without row rules behaves as before. See the
[rule sets guide](docs/external/rule-sets.md#row-rules). (#375)
