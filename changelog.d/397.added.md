Rule-set row rules gain three additions. The new `is_null` and `is_not_null`
kinds test a column for `NULL` (TOML has no null value, so `compare` cannot),
for example to hide soft-deleted rows. A `referenced_by` rule's `link.table`
may now be a table the set does not list: its two named columns are read only
inside the row rule, and the assistant still cannot query that table. An
`inherit` rule takes an optional `parent_rule`, a condition on the parent row
built from `compare`, `is_null`, `is_not_null`, `any_of` and `all_of`. A file
that uses any of these is refused by older SQL Lens versions, so upgrade before
deploying it. Restart SQL Lens after renaming or dropping any table or column a
rule set names. See the
[rule sets guide](docs/external/rule-sets.md#row-rules). (#377)
