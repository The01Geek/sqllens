Memory imports compare SQL by parsing it as MySQL, so reformatted SQL counts as
a duplicate while string values and identifiers keep their case; SQL that does
not parse as one statement matches only identical text. A duplicate now adds
its groups to the records it matches, and the import summaries report how many
records were updated (`updated=` from `sqllens import-memory`, an `updated` row
from `import_memory`, `updated_count` from `add_memories`). SQL Lens now
requires `chromadb` 1.5 or later. (#412)
