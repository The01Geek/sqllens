# Security policy

## Reporting a vulnerability

Please [report vulnerabilities privately through GitHub](https://github.com/The01Geek/sqllens/security/advisories/new). Do not open a public issue or pull request that discloses an unpatched vulnerability.

Include the affected version or commit, the impact, and a minimal reproduction using synthetic data. Do not include credentials, private database contents, customer information, personal information, or private infrastructure details.

Maintainers will review the report privately and coordinate fixes and disclosure. Please check the latest release when reporting a problem, and state whether you also reproduced it on the default branch.

For ordinary bugs and feature requests, use the public issue tracker as described in [CONTRIBUTING.md](CONTRIBUTING.md).
