# SQL Lens public release notes

The public docs/external/release-notes.md page is a frozen archive with links to
the canonical generated CHANGELOG.md and pending changelog.d fragments. Preserve
that page during ordinary docs updates; do not append or duplicate release notes
there. New release-note wording belongs only to the current PR's fragment under
the docs-release-notes pass. User guides remain normal editable documentation.
See changelog.d/README.md and docs/internal/releasing.md for the migration and
explicit historical-correction route.
